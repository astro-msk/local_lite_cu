# Python migration interfaces

The Python implementation lives in `litecu/`. Keep the Swift prototype as a reference; do not edit it during this migration.

`core.py` owns the loop. UI calls `Engine(model=..., drivers={"desktop": ..., "arc": ...}, emit=callback, settings=dict)` then `await engine.run(command)`. `engine.stop()`, `engine.pause()`, `engine.resume()`, `engine.respond(value)` are thread-safe. Emit callbacks receive JSON dictionaries with `type` (`status`, `node`, `approval`, `question`, `result`, `route`), `title`, `detail`, optional `id`, `status`, `options`, `elapsed`, `target`. UI displays these on its Qt main thread. Approval answers are `approve`/`reject`; clarification answers are plain text. Settings: `target` auto/desktop/arc, `approval` every/sensitive/full, `speak` bool, `max_steps` int, `idle_seconds` float. Engine methods can be called from UI thread; run is in an asyncio worker thread.

Drivers have `async snapshot() -> dict`, `async execute(action: dict) -> str`, optional `prepare()` and `close()`, and `instructions: str`. Snapshot keys: `context` text, `images` list of local file paths (retained until next snapshot/close), `summary`, optional `generation`. Action keys: `name`, `arguments`, `reason`, `sensitive`. Desktop coordinates use `display_id`, x/y in that display image, never a stitched global screenshot. A driver may raise `StaleObservation` or `UserInterruption` (defined in `core.py`); engine waits/reobserves/replans rather than replaying stale coordinates. Desktop exposes `user_activity: float` (time.monotonic timestamp), `activity_generation: int`, and `permissions() -> dict`. `pause_for_user` activity must exclude our tagged synthetic events. Idle waits are bounded and cancellable. Model decisions may contain a small `actions` array only for deterministic same-surface typing/key sequences, never blind batches of coordinate clicks/navigation. Switches and questions are explicit decisions.

`codex.py`: `CodexModel(model="gpt-6.1-sol")`; `async decide(prompt: str, images: list[str], schema: dict) -> dict`; `async plan(prompt: str, images: list[str]) -> str`; `cancel()`; `status() -> str`. Uses existing Codex sign-in, isolated model-only exec (no tools). `DemoModel`/`DemoDriver` from `core.py` for UI tests without permissions/network.

`ui.py`: `main()` is entrypoint; PySide6 UI, status HUD, settings, command palette, history, native local speech helpers. Wire drivers lazily for live mode to avoid permission prompts at launch. No real desktop input on UI startup or demo. Theme defaults light with red/blue/yellow/green controls. Keep previous Swift history readable or preserve it untouched; Python stores its own versioned history. Persist settings; never silently change approval policy.

Desktop implementation in `desktop.py` (+ `geometry.py` if useful). Arc implementation in `arc.py` with packaged fixed JS in `assets/`. Voice implementation in `voice.py`. Packaging scripts must retain bundle ID `local.litecu.app`, accept `LITECU_SIGNING_IDENTITY`, and clearly state ad-hoc signing does not preserve TCC grants across updates. Do not reset TCC or weaken signing requirements.
